Beginner-level Python practice covering Pandas data manipulation, filtering, conditional operations, and data visualization using Matplotlib and Seaborn.

The dataset contains fictional sample data created for educational purposes.
# Pandas-practice

# 1. Pandas Filtering Practice

## Overview

This project contains 10 beginner-level practice questions using Python Pandas to filter and analyze a banking customer dataset.

## Topics Covered

- DataFrame creation using Pandas
- Filtering rows using conditions
- Comparison operators (`>`, `<`, `>=`, `<=`, `==`)
- Combining conditions using `&` (AND) and `|` (OR)
- Filtering customers by age, city, gender, account type, balance, and loan amount

## Dataset

The dataset contains 20 sample customer records with the following columns:

- Customer_ID
- Name
- Age
- Gender
- City
- Account_Type
- Balance
- Loan_Amount

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Learning Outcome

Practiced conditional filtering in Pandas and learned to retrieve specific records from a structured dataset.

# 2. Data Visualization Practice — Matplotlib & Seaborn

## Overview

This section contains beginner-level data visualization exercises using Matplotlib and Seaborn to explore datasets, identify patterns, compare categories, and understand relationships between variables.

- Scatter plots
- Bar plots and count plots
- Box plots and outlier identification
- Histograms and distributions
- Line plots
- Heatmaps and correlation analysis
- Customizing charts with titles, labels, and colours

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Learning Outcome

Practiced creating and customizing visualizations, comparing customer groups, identifying potential outliers, exploring numerical distributions, and analyzing correlations between variables.
