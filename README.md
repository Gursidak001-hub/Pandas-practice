# Pandas-practice

Beginner-level Python practice covering data manipulation, filtering, conditional operations, data cleaning, and data visualization using Pandas, Matplotlib, and Seaborn.

This repository contains hands-on exercises and projects using fictional datasets created for educational and learning purposes.

---

# 1. Pandas Filtering Practice

## Overview

This project contains 10 beginner-level practice questions using Python Pandas to filter and analyze a banking customer dataset.

## Topics Covered

- DataFrame creation using Pandas
- Filtering rows using conditions
- Comparison operators (`>`, `<`, `>=`, `<=`, `==`)
- Combining conditions using `&` (AND) and `|` (OR)
- Filtering customers by age, city, gender, account type, balance, and loan amount

## Dataset

The dataset contains 20 sample customer records with the following columns:

- Customer_ID
- Name
- Age
- Gender
- City
- Account_Type
- Balance
- Loan_Amount

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Learning Outcome

Practiced conditional filtering in Pandas and learned to retrieve specific records from a structured dataset.

# 3. Bank Customer Data Cleaning Practice

## Overview

A hands-on data cleaning project using a messy bank customer dataset. This project focuses on identifying and handling missing values, duplicate records, inconsistent data, invalid entries, and incorrect data types using Pandas.

The practice includes 64 questions covering different stages of the data cleaning process.

## Topics Covered

- Understanding and exploring datasets
- Checking and handling missing values (Null values)
- Detecting and removing duplicate records
- Identifying unique values and value counts
- Cleaning and standardizing text data
- Detecting invalid values
- Identifying potential outliers using the IQR method
- Converting data types using Pandas
- Handling datetime values
- Filtering and sorting records
- Performing final data quality checks
- Exporting cleaned datasets to CSV

## Dataset

The project uses a fictional bank customer dataset containing customer information such as:

- Customer_ID
- Name
- Age
- Gender
- City
- Account_Type
- Active_Customer
- Monthly_Income
- Credit_Score
- Loan_Amount
- Join_Date

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Learning Outcome

Developed practical data cleaning skills by working with inconsistent datasets, handling missing and duplicate values, detecting potential outliers, standardizing records, and preparing datasets for further analysis.
